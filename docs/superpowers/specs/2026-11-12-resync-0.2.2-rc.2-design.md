# vendored 树重同步至 DSH 0.2.2-rc.2（0.4.1）

> 状态：已与用户确认关键决策
> 日期：2026-11-12
> 适用：`src/vendored/`、`src/client/project-menu.ts`、`package.json`
> 基线：`dsh-v0.2.2-rc.1`（当前 0.4.0）→ `dsh-v0.2.2-rc.2`

## 1. 意图

DSH 已发布 `0.2.2-rc.2`，用户已安装。本插件当前 vendored 树是 rc.1 形状，需要跟到 rc.2。

**这一次不是纯版本号的 patch**：`ui-workspace` 的源码改了 8 个文件、+190/−189，而其中 8 个全部是本插件打过补丁的文件。

## 2. 上游改了什么（rc.1 → rc.2）

| 包 | 改动 | 影响 |
|---|---|---|
| `ui-workspace/src` | 8 文件 +190/−189 | **需要重同步** |
| `ui-primitives` | `Menu` 删除 `getAnchorRect`，改 `anchorRef` / `anchorPoint` | **真实回归**：`WorkspacePicker.tsx` 仍在用 `getAnchorRect` |
| `ui-context-menu` | 新增 `ContextMenuButton` 工厂；`open()` 增加可选第三参 | 向后兼容 |
| `ui-sidebar` | `sidebar.workspaces` 新增 `hookContext` / `inject`，新增 `useSectionScroller` | 不接则回退原生滚动 |
| `ui-slots` | 新增 `hoc` 槽位类型 | 纯增量 |
| `cordis` / `schemastery` | **无变化** | 依赖不用动 |
| `engines.dsh` | 仍为 `>=0.2.2-rc.1 <0.2.3` | 已覆盖 rc.2 |

### `ui-workspace/src` 的具体改动

- `Rows.tsx`（+85/−85）：Workspace 行与会话行的菜单触发改为 `renderFactorySlot('contextMenu.button', { target, label, className })`；删除 `openWorkspaceMenu` / `openSessionMenu` 参数。
- `WorkspaceBrowser.tsx`（+66/−66）：把 `renderFactorySlot` 穿到各层；接入 `const { bindScrollerRef } = useSectionScroller()` 并挂到 `listArea`。
- `contract/slots.ts`（+11/−11）：`WorkspaceBrowserInjected` 删除 `openWorkspaceMenu` / `openSessionMenu`；`WorkspaceBrowserProps` 加 `PropsRenderFactories`；`RowToast` 增加 `message?` / `tone?`。
- `index.ts`（+62/−20）：删除两个菜单回调；新增 `workspace/archive-notice` 瀑布与 `archive-followup-failed/settled` 事件。
- `WorkspacePicker.tsx`（+10/−10）：`getAnchorRect` → `anchorRef`（配合 `Menu` API）。
- `toast/register.ts`（+30/−30）：`archived` / `stoppedAndArchived` 合并为循环，支持 `notice.message` / `notice.tone`。
- `Rows.module.css`（+12/−12）、`WorkspaceBrowser.module.css`（+103/−103）：工具栏高度变量、列表滚动区、rail 布局。

## 3. 已确认的决策

1. **版本号 `0.4.1`**：engines 未变、API 向后兼容，属维护性重同步。
2. **项目行菜单改用官方 `contextMenu.button` 工厂**：与上游一致，同时删掉自建的 `openProjectMenu` 管道。
3. **不做架构改动**：不拆文件、不改构建配置、不动现有功能实现。

## 4. 目标

- vendored 8 个文件与 rc.2 三方合并，所有本插件补丁点保留。
- `WorkspacePicker` 的菜单锚点改用 `anchorRef`，修复 rc.2 上的定位回归。
- 项目行用 `renderFactorySlot('contextMenu.button', { target: { kind: 'project', … } })`。
- `pnpm check` 全绿；关键探针在真实 rc.2 上通过。

## 5. 非目标

- 不新增功能；
- 不改 `directories` 数据形状；
- 不动 `AnimatedRows` 本地副本（rc.2 的 `ui-primitives` 里它的差异需单独确认，见计划 Task 2）；
- 不做与本次无关的重构。
