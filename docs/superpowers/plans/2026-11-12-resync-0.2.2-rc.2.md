# vendored 树重同步至 DSH 0.2.2-rc.2 实施计划（0.5.0）

> **For agentic workers:** 按任务顺序执行，每个任务独立提交。步骤用 `- [ ]` 跟踪。

**Goal:** 把 `src/vendored/` 从 rc.1 形状同步到 rc.2，保持本插件全部功能与上游 1:1。

**Architecture:** 以 `dsh-v0.2.2-rc.1` 为 base、当前 vendored 树为 ours、`dsh-v0.2.2-rc.2` 为 theirs 做三方合并；随后把项目行菜单改为上游的 `contextMenu.button` 工厂。

**Spec:** `docs/superpowers/specs/2026-11-12-resync-0.2.2-rc.2-design.md`

## Global Constraints

- 版本号 `0.4.0` → `0.5.0`
- `engines.dsh` 收紧为 `>=0.2.2-rc.2 <0.2.3`（rc.1 缺 `contextMenu.button` / `useSectionScroller`）
- 所有 `@deepseek-ai/dsh-*` devDependencies 升到 `0.2.2-rc.2`
- `zod` 保持精确 `4.4.3`
- **红线：不得导致任何今天可用的功能无法加载或缺失**
- 60 处分组接缝必须仍为 60（出现次数口径）
